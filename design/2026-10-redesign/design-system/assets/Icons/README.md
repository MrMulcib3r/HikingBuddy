# Icons

Custom hiker icons drawn on Lucide's 24px grid (stroke 1.75, round caps) so they sit next to Lucide icons. The files here are single-ink in `ink` (#2B1D24); in the app use the `HB.icons` versions in `components/bundle.js`, which draw with `currentColor`.

- `worn-boot.svg`: Worn flag, Worn weight tile.
- `linked-carabiner.svg`: "used in gearlists" badge and the 3-way dialog title.
- `hiker.svg`: worn weight beside the backpack chart.
- `hikingbuddy-mark.svg`: the app mark (backpack with a peak), multi-colour: accent body, ink loop, surface peak.

Consumable uses Lucide `utensils`, Food keeps Lucide `apple`. Every other icon is Lucide (already in the app as `lucide-react`).
