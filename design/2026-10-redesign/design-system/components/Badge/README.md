# Badge

Small status pill. `--linked` with the carabiner icon marks a Gear Vault item used in gearlists (carabiner + "2 lists" as text in rows; tooltip "Editing it changes these gearlists too"). `--warning` marks a gearlist row whose Vault item was deleted ("Not in Gear Vault"). `--success` shows a saved snapshot or a connected data file.

PRD v33 (Activity): `--ai` (`accent-soft`, Lucide `bot`, the AI client's name: "Claude") and `--you` (neutral with a hairline, Lucide `user`, "You") say who made a change, always in words; `--deleted` (`danger-soft`, `trash-2`, "Restorable until 20 Nov") marks a soft-deleted thing; `--undone` (neutral, `check`, "Undone 14:40") marks an entry that was undone.
