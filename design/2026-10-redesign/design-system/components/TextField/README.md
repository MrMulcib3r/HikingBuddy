# TextField

Labelled input for dialogs (`hb-field` + `hb-label` + `hb-input`) and the Gear Vault search (`hb-search`).

- Labels are uppercase display labels; placeholders show an example ("e.g. Snickers"), never the label again.
- Errors: add `is-error` and a `hb-field-error` line that says how to fix it.
- Search sits on `surface-sunken` without a border until focused.
