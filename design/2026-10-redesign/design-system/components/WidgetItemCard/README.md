# WidgetItemCard

One Gear Vault item, or one row of a gearlist, in the chat (PRD v33, FR-27).

- Name (`w-title`), category (dot, icon, name), weight in `w-total` style (Barlow 28px, tabular).
- Note in a `surface-sunken` box; "No note" is not shown, the box is just left out.
- Facts (`hbw-facts`): "In gearlists" with the carabiner and their names (or "Not in any gearlist"); from a gearlist also Quantity, and Worn / Consumable as text badges only when set.
- Foot: "Open in HikingBuddy" opens the item in the Gear Vault (or the gearlist row). No edit buttons: changes go through the chat, and FR-5 still applies there.
