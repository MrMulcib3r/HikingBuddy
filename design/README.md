# design/

Podklady k vzhledu appky: wireframy, náčrty, screenshoty s poznámkami, inspirace z jiných aplikací.

## Pravidla
- **Pojmenování:** `RRRR-MM-DD-co-to-je.png`, např. `2026-09-24-gearlist-redesign.png`, `2026-09-24-bug-kategorie.png`.
- **K obrázku vždy text:** buď odkaz v položce v `BACKLOG.md`, nebo vedle obrázku `.md` soubor se stejným jménem, který popisuje **chování** (co se stane po kliknutí, co je důležité). Obrázek ukáže rozložení, ale ne chování.
- **Větší redesign:** vlastní podsložka, např. `design/2026-10-redesign/`, s obrazovkami a jedním `README.md`, který popisuje celek.

## Pro Claude Code
Když má položka v backlogu odkaz na soubor v `design/`, otevři si ho a řiď se jím. Když se návrh a PRD rozcházejí, zeptej se Martina.
